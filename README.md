
TEAC-DUNE: Busca do X(17) no DUNE

Código para reproduzir a predição da Teoria dos Estados Atômicos Condicionais (TEAC) para descoberta do bóson X(17) de 16.94 MeV no experimento DUNE.

 Resultado Principal
Para acoplamento $g_X = 6 \times 10^{-4}$, o DUNE Phase-II detecta ~600 eventos/ano em $p_{\pi^+} = 219$ MeV. Background < 10 eventos. Significância > 50σ.

python dune_x17_teac.py
